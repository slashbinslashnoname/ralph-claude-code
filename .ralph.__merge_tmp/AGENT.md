# Build & Run — Slashbot

## Install
```bash
bun install
```

## Dev
```bash
bun run dev
```

## Build
```bash
bun run build
```

## Stack
- Electron 33 + electron-vite + React 18 + TypeScript
- Package manager: Bun
- Source: src/main/, src/preload/, src/renderer/
